# KinOnline
Free viewing of movies and series on [Kinopoisk](https://www.kinopoisk.ru) / [IMDb](https://www.imdb.com).
</br>
# Installing
1. Install the extension for the browser [Tampermonkey](https://www.tampermonkey.net).
2. Install for [Kinopoisk](https://github.com/StaticHUN/KinOnline/raw/rue/KinOnlineForKinopoisk.user.js) / [IMDb](https://github.com/StaticHUN/KinOnline/raw/rue/KinOnlineForIMDb.user.js).
3. The button is located top of the poster or top "Add to Watchlist" button
